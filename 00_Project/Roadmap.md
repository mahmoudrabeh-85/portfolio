# Roadmap

## Phase 0 - Safety and audit

- نسخ الصفحة الحالية.
- ضبط `meta charset="UTF-8"` والتأكد من حفظ الملف UTF-8.
- استبدال رقم WhatsApp والرابطين التجريبيين ببيانات حقيقية أو placeholders.
- حصر أي ادعاء رقمي يحتاج إثباتاً.

## Phase 1 - Profile and offer

- بناء hero واضح: الاسم، الوعد، الخبرة، زر التواصل.
- إضافة الخدمات والأسواق المستهدفة والأسعار الابتدائية من المستند المرجعي.
- إضافة قسم "كيف أساعدك" بصياغة نتائج لا مهام فقط.

## Phase 2 - Portfolio proof

- تحويل النماذج الثلاثة إلى بطاقات case study.
- إضافة المشكلة، المنهج، المخرجات، النتيجة، وما يمكن تحميله.
- منع أزرار التحميل من الإشارة إلى ملفات غير موجودة.

## Phase 3 - Conversion and quality

- إضافة نموذج تواصل أو رابط بريد حقيقي.
- تحسين SEO وOpen Graph وschema أساسي.
- اختبار الهاتف، لوحة المفاتيح، RTL، الروابط، والنوافذ المنبثقة.

## Phase 4 - Growth

- إضافة LinkedIn وUpwork وlead magnet.
- نشر محتوى أسبوعي.
- إضافة منتجات Excel وSOPs ثم dashboards تفاعلية.
