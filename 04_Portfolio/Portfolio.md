# Portfolio Structure

كل عنصر يجب أن يحتوي على: العميل/القطاع (إن أمكن)، المشكلة، الدور، الحل، المخرجات، النتيجة، الأدوات، وحدود السرية.

## Initial showcase

1. RFP Template - Procurement Documentation
2. Vendor Evaluation Scorecard - Vendor Evaluation
3. Supply Contract Template - Contract Drafting
4. Excel Inventory Dashboard - يضاف بعد تجهيز ملف أو screenshot حقيقي
5. Demand Planning Model - يضاف بعد تجهيز نموذج قابل للعرض

## Case-study rules

- لا تستخدم أسماء عملاء أو نتائج غير مصرح بها.
- النماذج التوضيحية تحمل label: `Illustrative sample`.
- زر Preview يعمل دائماً.
- زر Download يظهر فقط إذا كان الملف موجوداً وقابلاً للتنزيل.
