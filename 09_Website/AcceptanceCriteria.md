# Acceptance Criteria

- الصفحة تفتح دون أخطاء JavaScript في console.
- العربية تظهر سليمة بلا mojibake أو رموز مثل `Ù…`.
- العنوان والوصف وCTA مفهومة خلال أول شاشة.
- كل رابط تواصل يفتح وجهته الحقيقية بعد إدخال البيانات الفعلية.
- لا يوجد زر Download لملف غير موجود.
- النوافذ المنبثقة تفتح وتغلق بالزر وEscape ولا تحبس الصفحة.
- التصميم يعمل على 360px و768px و1440px.
- التنقل ولوحة المفاتيح وfocus states تعمل.
- كل ادعاء رقمي غير موثق إما مؤكد أو موسوم `To be verified`.
- OpenCode يشغل فحصاً يثبت وجود الملفات المشار إليها قبل التسليم.

## Definition of done

يتم اعتبار MVP جاهزاً فقط بعد تحقق كل البنود أعلاه، ومراجعة بشرية للمحتوى، وتأكيد بيانات الاتصال.
