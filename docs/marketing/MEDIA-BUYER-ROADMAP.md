## المرحلة 1: المنصة واللغة (أسبوع 1)

### 1.1 المنصات المهمة لك (بترتيب الأولوية حسب سوق مصر)

| المنصة | القوة | متى تستخدمها |
|---|---|---|
| **Meta (فيسبوك + انستجرام)** | الأقوى في مصر — 45M+ مستخدم | منتجات/خدمات B2C + B2B مصري |
| **Google Ads** | نية شراء عالية (يبحث عنك) | خدمات استشارية (يبحث الناس عن "مستشار مشتريات") |
| **TikTok Ads** | انتشار سريع، جمهور شاب | منتجات عامة + فيديوهات جذابة |
| **LinkedIn Ads** | الأغلى لكن الأدق B2B | عملاء خليج/أمريكا (مرحلة لاحقة) |

### 1.2 المصطلحات التي ستسمعها يومياً (احفظها)

| المصطلح | المعنى بالعربي | ماذا يعني لك عملياً |
|---|---|---|
| **CPM** | تكلفة كل 1000 مشاهدة | مؤشر تكلفة الوصول — الأقل أفضل نسبياً |
| **CTR** | نسبة النقر إلى المشاهدة | مقياس جاذبية الإعلان — الهدف 1%+ |
| **CPC** | تكلفة النقرة الواحدة | كم تدفع مقابل نقرة |
| **CPA** | تكلفة الإجراء (شراء/رسالة) | الهدف النهائي — أقل هو الأفضل |
| **ROAS** | العائد على الإنفاق الإعلاني | كل جنيه إنفاق = كم جنيه مبيعات |
| **CBO** | تحسين الميزانية على مستوى الحملة | ميزانية واحدة توزع تلقائياً على أفضلها |
| **ABO** | ميزانية منفصلة لكل مجموعة إعلانية | تحكم يدوي كامل |
| **Pixel / CAPI** | كود التتبع في موقعك | يعرف النظام من أتم إجراءً فعلياً |
| **Lookalike** | جمهور مشابه لعملائك الحاليين | أقوى استهداف بعد البيكسل |
| **Retargeting** | إعادة الاستهداف (زائر سابق) | أبرد إلى أسخن جمهور |
| **Frequency** | عدد مرات مشاهدة نفس الشخص للإعلان | أعلى من 3 = إزعاج وإهدار |
| **Creative Fatigue** | إرهاق الإعلان (قل التفاعل بمرور الوقت) | اعرف متى تبدّل الإعلان |

## المرحلة 2: المعسكر العملي (أسبوعان)

### الأسبوع 1 — بناء الأدوات

1. **أنشئ حساب Meta Business (إن لم يكن):**
   - business.facebook.com/overview
   - اربط صفحتك الفيسبوك + حساب انستجرام
   - أضف طريقة دفع (فيزا) — لا تحمّل أي مبلغ الآن

2. **ركّب Meta Pixel على موقعك:**
   - dashboard: Events Manager → Connect Data → Web → Meta Pixel
   - ضع الكود في `<head>` من portfolio.html (أو عبر Google Tag Manager إن أردت)
   - ثبّت امتداد المتصفح "Meta Pixel Helper" للتحقق
   - **لماذا هذا قبل كل شيء؟** بدون بيكسل لا تعرف من اشترى — تخسر نصف قوة الإعلانات

3. **افتح حساب Google Ads:**
   - ads.google.com → إعداد أساسي (لا تحمّل مبلغاً بعد)
   - اربطه مع Search Console لموقعك

### الأسبوع 2 — تعلم البنية الصحيحة

**قاعدة المسار الصحيح في Meta:**

```
حملة (Campaign) → هدف واحد واضح
└── مجموعة إعلانية (Ad Set) → جمهور واحد
    └── إعلانات (Ads) → 3+ نسخ مختلفة (نص/صورة/فيديو)
```

**التعلم المطلوب هذا الأسبوع:**
- التجول في Ads Manager (المسارات، التخطيط، الشروح)
- فهم أنواع الأهداف: Awareness → Traffic → Engagement → Leads → Sales
- الفرق بين الجمهور البارد (Cold) والدافئ (Warm) والساخن (Hot)
- مشاهدة 3-5 تجارب حية لحملات فيديو تعليمية (Meta Blueprint مجاني)

## المرحلة 3: أول حملة حقيقية (أسبوع 3)

### التصور: حملة تعريفية لخدمتك الاستشارية

**الهدف:** ليس بيعاً — بل **رسائل واتساب** (أسهل هدف للتعلم + يناسب العميل المصري)

| الإعداد | القيمة |
|---|---|
| **الهدف** | Engagement أو Leads (Messages) |
| **الميزانية** | 100-150 جنيه/يوم لمدة 5 أيام (= 500-750 جنيه إجمالي) |
| **الجمهور** | مصري، 25-55، اهتمامات: أعمال/تجارة/صيدلة |
| **الإعلان 1** | صورة نصية: "مستشار مشتريات... 20 مليون جنيه شهرياً" |
| **الإعلان 2** | فيديو قصير (تيك توك قديم أو جديد): "خطأ مخزون يكلفك" |
| **الإعلان 3** | نص فقط: سؤال تفاعلي في المنشور |
| **مكان النشر** | فيسبوك (الشبكة) + انستجرام (الستوري) |

**مصطلح مهم:** تعلّم معنى الـ **Test Phase** — أول 3 أيام هي "(اختبار التعلّم)". لا تحكّم على النتائج قبل أن يمر `Learning Phase` للنظام (حوالي 50 تحويلاً في الأسبوع أو أقل).

### ماذا ستراقب يومياً؟

| اليوم | ماذا تفعل |
|---|---|
| 1 | أطلق الحملة — لا تغيّر شيئاً |
| 2-3 | راقب: CPM (هل هو معقول؟ < 50 جنيه جيد في مصر) |
| 4 | قيّم الإعلانات: أي نسخة أفضل CTR؟ |
| 5 | أوقف الإعلان الأسوأ، ضاعف ميزانية الأفضل |

## المرحلة 4: قواعد التوسع المنضبط (الأسابيع 4-8)

### قواعد لا تُكسر (من تجارب المحترفين)

1. **لا تضاعف الميزانية أكثر من 30-40% مرة واحدة** — القفزات الكبيرة توقّف "التعلّم" وتخرب النتائج
2. **بدّل الإعلان عند "إرهاق" (Creative Fatigue)** — إذا انخفض CTR بعد 7-10 أيام، نسخة جديدة
3. **استهدف النتيجة لا الميزانية** — كل جنيه جديد يجب أن يجلب نسبة عائد مشابهة أو أفضل
4. **واحد في كل مرة** — لا تغيّر أكثر من متغير واحد بين الاختبارات (الجمهور أو النص أو الصورة... فقط واحد)
5. **بيكسل يعمل = كل شيء** — تأكد أسبوعياً أن التحويلات تُسجّل (Marketing API → Checkout)
6. **سجّل كل شيء** — جدول Excel بسيط: تاريخ/ميزانية/نقرات/رسائل/تكلفة/عائد

### تدرج الميزانية (حسب النتائج)

```
الأسبوع 3: 500-750 جنيه إجمالي (تعلم)
الأسبوع 4: 100-150 جنيه/يوم (نفس الحملة المُحسّنة)
الأسبوع 5: 150-200 جنيه/يوم (إذا ROAS ≥ 2)
الأسبوع 6: جمهور جديد (Lookalike من تفاعلات أول حملة)
الأسبوع 7: حملة Retargeting (زوار الموقع + تفاعلات الصفحة)
الأسبوع 8: حملة Google Ads (كلمات: "مستشار مشتريات مصر")
```

**متى تزيد؟** فقط عندما تثبت النتائج: يزيد ROAS أو تنخفض CPA خلال 3-4 أيام متتالية. وإلا تثبّت ولا تتوسع.

## المرحلة 5: البيع الاحترافي للعملاء (الأسابيع 9+)

### متى تصبح "محترفاً" بلا كذب:

- [ ] شغّلت 3+ حملات ناجحة (لنفسك أو لأصدقاء مجاناً)
- [ ] تفهم التقرير اليومي: CPM/CTR/CPC/CPA/ROAS بطلاقة
- [ ] بنيت 3 تجارب مختلفة (منتج/خدمة/صفحة)
- [ ] حصلت على أول "نتيجة قابلة للعرض" (Case Study)
- [ ] أتقنت صيانة البيكسل والتحويلات

### التسعير في السوق المصري/العربي:

| النموذج | السعر التقريبي | متى |
|---|---|---|
| **إدارة شهرية** (ميزانية + رسوم) | 2000-5000 جنيه/شهر أو 10-15% من الميزانية | الأكثر شيوعاً |
| **رسوم + نسبة** (ميزانية + 10% + بونص على النتائج) | 10% رسوم + بونص إذا تجاوزت ROAS متفقاً عليه | احترافي |
| **عمولة فقط** (نسبة من المبيعات) | 15-25% من المبيعات المسجلة بالبيكسل | مخاطرة عالية — لاحقاً |
| **شهري ثابت** (إدارة كاملة) | 5000+ جنيه للشركات الأكبر | بعد سمعة |

### حزمة الخدمة الاحترافية (عرضك للعملاء):

```
[إعلانك يومياً]
└── استهداف دقيق (جمهورك)
├── 3+ إعلانات مُختبَرة
├── بيكسل وتتبع محسّن
├── تقرير أسبوعي (Excel بسيط)
└── اجتماع شهري (واتساب/Zoom)
```
