# Mahmoud Rabeh Portfolio - OpenCode Execution Specs

هذه المواصفات هي مصدر الحقيقة لتنفيذ portfolio مهني لمحمود رباح، خبير المشتريات وسلاسل الإمداد بخبرة 18+ سنة.

## ترتيب التنفيذ

1. `00_Project/Roadmap.md`
2. `01_Profile/ME.md`
3. `03_Business/Services.md`
4. `04_Portfolio/Portfolio.md`
5. `09_Website/PRD.md`
6. `09_Website/Content.md`
7. `09_Website/AcceptanceCriteria.md`

## تعليمات OpenCode

- اقرأ ملفات المواصفات قبل تعديل `portfolio.html`.
- نفّذ مرحلة واحدة فقط في كل مرة.
- بعد كل مرحلة شغّل فحص HTML وافتح الصفحة في المتصفح للتحقق البصري.
- لا تخترع أرقاماً أو شهادات أو شعارات عملاء؛ استخدم placeholders واضحة عند غياب الدليل.
- حافظ على العربية والإنجليزية مع `UTF-8` واتجاه RTL صحيح.

## مصادر المراجعة

- `Mahmoud_Rabeh_Master_Consulting_Starter.docx`: الهوية والخدمات والأسعار والخطة الأولية.
- `portfolio.html`: النسخة الحالية التي تحتاج إعادة تنظيم وإصلاح ترميز ومحتوى.
